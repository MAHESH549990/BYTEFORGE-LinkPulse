# LinkPulse

LinkPulse is a URL shortener and analytics platform that converts long URLs into short, shareable links. It tracks link clicks and provides analytics to help users understand their link performance.

## Features

- Shorten long URLs
- Create custom short links
- Track link clicks
- View link analytics
- Manage shortened links
- Generate QR codes
- User authentication
- Admin dashboard

## Tech Stack

- **Frontend:** EJS, HTML, CSS, Bootstrap, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Charts:** Chart.js

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the backend folder:

   ```bash
   cd LinkPulse/backend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your environment variables in the `.env` file.

5. Start the development server:

   ```bash
   npm run dev
   ```

## Goal

The goal of LinkPulse is to provide a simple and reliable platform for shortening URLs and tracking their performance.
